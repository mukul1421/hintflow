# HintFlow

> Learn how to think, not what to type.

HintFlow is an AI-powered Chrome extension that transforms LeetCode into an interactive learning experience. Instead of generating complete solutions, HintFlow analyzes the user's approach, understands their code, and provides adaptive hints, interview-style guidance, and personalized feedback to help developers strengthen their problem-solving skills.

---

## 🚀 Vision

Build an AI mentor that teaches users **how to think** instead of simply telling them **what to code**.
